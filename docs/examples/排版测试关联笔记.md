# 一张关于观察的写作卡片

这是一篇供长文嵌入的独立笔记。它不依赖仓库里已有的个人内容。

## 一条观察

当我们把“事情很难”改写成“我还没有确认下一步”，一个笼统的感受就变成了可以继续追问的问题。记录因此多了一点具体，也多了一点行动的可能。 ^sample-observation

## 三个动作

- 描述自己真正看见的事情。
- 区分事实、推测与感受。
- 留下一个可以再次检查的问题。
